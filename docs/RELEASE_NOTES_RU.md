# Выпуск «Мишка»: прошивка v0.5.8.23.1 + интеграция v0.5.9.4

**Статус:** исходный код опубликован; отдельный GitHub Release и готовые BIN-образы ещё не опубликованы.

## Состав
- `firmware/` — ESP-IDF 5.5.6, ESP32-S3, микрофоны ES7210, аудиовыход ES8311, локальная модель ключевого слова `mishka.tflite`, Assist по WebSocket, интернет-радио, MQTT, LED WS2812 и веб-интерфейс.
- `custom_components/mishka_speaker/` — пользовательская интеграция Home Assistant версии `0.5.9.4`, конфигурация и сущности.
- `docs/INSTALL_RU.md` — сборка, установка и настройка.

## Подтверждённые проверки на устройстве
Проверялись обнаружение слова «Мишка», команды через Home Assistant Assist, воспроизведение TTS, возврат радио после ответа, индикация Assist и взаимодействие по MQTT. Это результаты испытаний используемой установки, а не гарантия совместимости со всеми конфигурациями.

## Установка
См. [инструкцию](INSTALL_RU.md). Для сборки необходим ESP-IDF 5.5.6; интеграция устанавливается копированием каталога в `/config/custom_components/mishka_speaker/`.

## Ограничения
- AEC (акустическое эхоподавление) не реализовано.
- Отдельная контрольная сборка из опубликованного дерева GitHub не выполнялась.
- Не публикуйте `sdkconfig`, токены Home Assistant, пароли Wi-Fi/MQTT и дампы NVS.

## План публикации Release
После сборки и проверки прошивочного BIN создать выпуск с тегом `v0.5.8.23.1` и приложить BIN с указанием адреса прошивки и способа обновления. Интеграция в том же исходном дереве имеет собственную версию `v0.5.9.4`. Не путать тег прошивки с версией интеграции.
